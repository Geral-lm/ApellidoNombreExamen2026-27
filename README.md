<h1>Sistema de Préstamos de Biblioteca</h1>
Aplicación en Java para gestionar los préstamos de una biblioteca. Permite registrar libros y 
socios, prestar libros disponibles (máximo 3 por socio) y devolverlos. 

<h2>Uso</h2>
1. Clona el repositorio:<br>
git clone https://github.com/victorvergelgregorio/ApellidoNombreExamen2026-27.git <br>
2. Copia config/secretos.properties con tus credenciales (no se sube al repositorio).<br>
3. Compila el proyecto desde la carpeta src:<br>
javac -d out Main.java modelo/*.java servicio/*.java <br>
4. Ejecuta la aplicación: <br>
java -cp out Main <br>
5. Ejecuta los tests de test/PrestamoTest.java con JUnit 5. <br>
